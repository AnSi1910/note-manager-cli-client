# Менеджер нотаток (фронтенд)

Повноцінний вебзастосунок для обліку нотаток з категоріями та пошуком. Проєкт розроблений в межах навчальної практики з програмування (Частина 3).

## Технологічний стек
- Back-end: Node.js, Express, SQLite, Sequelize ORM, Swagger.
- Front-end: React, Vite, SCSS, Axios, localStorage.

## Інструкція зі встановлення та запуску

### 1. Запуск серверної частини (Back-end)
1. Перейдіть у папку сервера (`note-manager-server`)
   ```bash
   cd note-manager-server
   npm install
   npm start
### 2. Запуск кліентської частини (Front-end)
2. Перейдіть у папку клієнта (`note-manager-client`)
   ```bash
   npm install
   npm run dev
### 3. Відкрийте ваш браузер та перейдіть по посиланню:
   ```bash
   http://localhost:5173
